# Отчёт о состоянии приложения — 11.11.2026

## Что сделано

- Добавлены список из 20 run с сортировкой и фильтром, страницы `/runs/:id`, карточки сводки, три графика, загрузка, пустое и ошибочное состояния, адаптивная сетка и управление диапазоном мышью и клавиатурой.
- Подготовка данных и выборка видимого диапазона выполняются в worker. При выборке сохраняются границы интервала, локальные экстремумы и все обнаруженные Warnings; Run-20 теперь содержит шесть всплесков, включая шаг 500 000. Это отклонение от исходного ТЗ с единственным всплеском. Ответы привязаны к ID запроса и run.
- `NaN`/`Infinity`, пропуски и дубликаты разрывают соответствующую линию. Значения дубликатов доступны в списке проблем и показаны отдельными маркерами. Карточки рассчитываются по полному набору конечных значений.
- Подготовлены тесты, вывод проверок, документация и конфигурация прямых ссылок для Vercel.
- Добавлена отдельная категория Warnings для одиночных всплесков loss. Она рассчитывается по полному ряду до выборки графика, показывает счётчик и позволяет приблизить каждый найденный шаг через Inspect. Порог: минимум в 3 раза выше обоих соседей и минимум на 1 больше ближайшего из них; соседние всплески и длительный рост могут не сработать.
