## Truthfulness

Run-20 has 1,000,000 points, two dense 1,000-point regions with two and three loss spikes, and the original spike of 500 at step 500,000. **This no longer meets the original requirement for a million-point run with a single middle spike.** A worker prepares each run once and reuses its raw data for zoom. Each visible range is sampled by metric, retaining bucket boundaries and extremes. Dense warning regions use half-size buckets, and every detected Warning point is retained in the loss series. Invalid metric values and missing steps become gaps, not zero. NaN and Infinity are marked by red dots at their step, with a symbolic y-position stated in the chart caption. Duplicate steps are listed with all raw values and plotted as separate amber markers without a connecting line. Original unsorted rows are reported and plotted in step order. The cards use unsampled finite values. The Warning rule is an isolated loss at least 3× both adjacent values and at least 1 higher; it still misses adjacent spikes and sustained rises. Axes name step and metric; tick labels use a fixed locale and tooltip values display the underlying sampled number without rounding.

Zoom leaves the previous chart and its old step label visible until the worker returns, then swaps in the new series. A status appears after 200 ms if needed; range errors retain the previous view. Initial load and run changes still show the full loading state.

## Silent failures checked

Requests carry monotonically increasing IDs. A result is displayed only when both ID and run match the current selection; a previous worker is terminated when the run changes. This addresses the A → B → A stale-result case in code, but it has not been verified by a browser race test. Linear chart segments are used, so smoothing is not applied. The y-axis uses a linear scale, including zero safely; no logarithmic scale is offered. Steps are integers without time-zone conversion. Number display uses an explicit `en-US` locale. Invalid values are counted and visible in the issue list rather than silently averaged away.
